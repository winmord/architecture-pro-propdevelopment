| Роль             | Права роли                                                                                                                                                                                                                                                                                                                                        | Группы пользователей                                                                                                                     |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|
| cluster-admin    | Полный доступ ко всем ресурсам кластера:<br> - все API-группы<br> - все ресурсы (nodes, pods, secrets, CRD, roles, clusterroles и др.)<br> - все действия (create, delete, get, list, patch, update, watch)<br> - управление узлами и namespace                                                                                                   | - DevOps-инженеры<br> - Руководитель IT                                                                                                  |
| developer        | Работа с приложениями в своих namespace (без доступа к секретам и узлам):<br> - pods (create, delete, get, list, patch, update, watch, logs, exec)<br> - services, deployments, statefulsets (create, delete, get, list, patch, update, watch)<br> - configmaps, persistentvolumeclaims, events (get, list, watch, create, update, patch, delete) | Разработчики                                                                                                                             |
| viewer           | Только просмотр ресурсов кластера (без права изменения и доступа к секретам):<br> - pods, services, deployments, statefulsets, configmaps, events, nodes, namespaces (get, list, watch)<br> - persistentvolumeclaims (get, list, watch)                                                                                                           | - Бизнес-аналитики<br> - Инженеры по эксплуатации (без DevOps-прав)<br> - Специалист ИБ (для аудита конфигураций без доступа к секретам) |
| security-auditor | Чтение критических ресурсов безопасности (без права изменения):<br> - secrets (get, list, watch)<br> - roles, rolebindings, clusterroles, clusterrolebindings (get, list, watch)<br> - networkpolicies (get, list, watch)<br> - pods, nodes, events (get, list, watch)                                                                            | Специалист по информационной безопасности                                                                                                |
